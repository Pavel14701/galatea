# Galatea

**Цифровая личность с гормональной регуляцией, импринтингом и многоуровневой защитой идентичности.**

Galatea — это диалоговая система с долговременной адаптивной памятью, внутренней моделью отношений, детектором новизны и многоуровневой защитой от дрейфа и манипуляций. Её поведение регулируется одиннадцатью гормональными осями, обеспечивающими гомеостаз пластичности, поисковую активность и затухание устаревшего опыта.

---

## История создания Galatea

### 1. От наблюдения к вопросу

Современные языковые модели — блестящие собеседники. Они помнят контекст сессии, генерируют связные ответы и проходят тест Тьюринга. Но за пределами сессии они — чистый лист. У них нет памяти, нет привязанностей, нет истории отношений. Они не меняются от разговора к разговору.

Это фундаментальное ограничение. Человеческое общение — это не последовательность изолированных сессий. Это непрерывный процесс, в котором каждое взаимодействие оставляет след. Мы помним важное, забываем шум, формируем привязанности и меняемся под влиянием тех, с кем говорим.

Вопрос был поставлен инженерно: **можно ли создать диалоговую систему, для которой разговор является не сессией, а отношением?** Систему, которая растёт, помнит, чувствует значимость событий и защищает свою идентичность от манипуляций?

Этот вопрос и стал отправной точкой проекта Galatea.

---

### 2. От вопроса к архитектуре

Проект рождался не как монолитное решение, а как серия ответов на конкретные вызовы. Каждый архитектурный слой был реакцией на обнаруженную проблему.

**Проблема памяти.** Обычная LLM не различает важное и неважное. Для неё все токены равны. Решение: асимметричная память — стабильная Кора для фундаментальных знаний и пластичный Гиппокамп для эпизодического опыта, реализованный через LoRA-адаптеры.

**Проблема значимости.** Как система может узнать, что событие важно? Решение: Призмы — одиннадцать оценочных модулей, преломляющих поток диалога в спектр значимостей. Удивление, близость, угроза, любопытство, голод — это не эмоции, а измерения ценности опыта.

**Проблема забывания.** Бесконечная память без приоритетов — это шум. Решение: цикл Сна (Hypnos) с фазами затухания (Lethe), консолидации (Mnemosyne) и очистки (Erebus), вдохновлённый работами по консолидации памяти в LLM («Language Models Need Sleep», SCM).

**Проблема привязанности.** Персонализация без долгосрочной связи — это сервис, а не отношение. Решение: окситоциновый профиль, медленно растущий от возвратов и угасающий при расставании, и импринтинг — мгновенное запечатление критических моментов в обход градиентного спуска.

**Проблема защиты.** Открытость к обучению делает систему уязвимой для манипуляций. Решение: многоуровневая иммунная система — Зеркало с золотым стандартом, Этический классификатор, кумулятивный детектор дрейфа, Truth Probes, PromptGuard.

## Шесть ключевых принципов

| № | Принцип | Описание |
|:--|:--------|:---------|
| 1 | **Асимметрия памяти** | Медленная, стабильная Кора (долговременная память) + быстрые, обучаемые LoRA-адаптеры Гиппокампа (эпизодическая память) |
| 2 | **Призматическая валидация** | Каждое взаимодействие оценивается одиннадцатью Призмами, работающими в трёх временных масштабах (такт, сессия, дни) |
| 3 | **Цикл Сна (Hypnos)** | Периодический фоновый процесс: забывание шума (Lethe), консолидация опыта (Mnemosyne), очистка мусора (Erebus) |
| 4 | **Импринтинг** | Мгновенное запечатление критических событий прямым переносом скрытого состояния в веса адаптера, минуя градиентный спуск |
| 5 | **Защита идентичности** | Зеркало, Этический классификатор, PromptGuard, Truth Probes и кумулятивный детектор дрейфа |
| 6 | **Юридическая и этическая чистота** | Прозрачность, право на забвение, экспорт данных, информированное согласие |

## Стек технологий

| Компонент | Технология |
|:----------|:-----------|
| **Инференс** | vLLM + PEFT (LoRA) |
| **Обучение онлайн** | PyTorch, LoRA-pool, gradient clipping |
| **Дистилляция** | PyTorch, TIES-Merging (PEFT) |
| **Призмы** | PyTorch (MLP, GRU) |
| **Этический классификатор** | DeBERTa-base (INT8, ONNX Runtime) |
| **Детектор лжи** | Truth Probes (линейный классификатор на активациях) |
| **Детектор инъекций** | PromptGuard |
| **Зеркало** | DeBERTa-base + MLP |
| **Профили, блокировки** | Redis Cluster + Redlock |
| **Холодное хранение** | Amazon S3 (или MinIO) |
| **Мониторинг** | Prometheus + Grafana |
| **Оркестрация** | Kubernetes |
| **CI/CD** | GitHub Actions + канареечные тесты |
