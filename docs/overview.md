# Заключение — полная архитектурная схема Galatea

## Ключевые цифры архитектуры

| Компонент | Количество / Описание |
|:----------|:----------------------|
| **Кора** | 1 — долговременная память |
| **Призмы** | 11 — гормональная система |
| **Адаптеров на пользователя** | 5 — эпизодическая память |
| **Фазы Сна** | 3 (Lethe, Mnemosyne, Erebus) — консолидация и очистка |
| **Механизмы защиты** | 4 (Зеркало, Этический классификатор, PromptGuard, Truth Probes) |
| **Золотой стандарт** | 1 (100 промптов v0) — якорь стиля |
| **Ключевые сценарии** | 10 — для обязательного тестирования в CI/CD |

---

## Полная архитектурная схема

Ниже представлена полная архитектурная схема Galatea 

```mermaid
graph TD
    User["ПОЛЬЗОВАТЕЛЬ (user_id)<br/>· Отправляет запрос x_t<br/>· Управляет памятью: /galatea-memory, /galatea-forget-me, /galatea-learning on/off"]

    subgraph Online["ОНЛАЙН-КОНВЕЙЕР (такт диалога)"]
        Step1["Шаг 1: Загрузка профиля"]
        Step2["Шаг 2: Кора + адаптеры"]
        Step3["Шаг 3: Этический класс. (асинхр.), PromptGuard"]
        Step4["Шаг 4: SP, BP, TP"]
        Step5["Шаг 5: Агрегация λ_t, AP, Импринтинг"]
        Step6["Шаг 6: Отложенное обучение Гиппокампа (двойной буфер)"]
        Step7["Шаг 7: Эго-контур, гормоны"]
        Step1 --> Step2 --> Step3 --> Step4 --> Step5 --> Step6 --> Step7
    end

    subgraph Prisms["ПРИЗМЫ (11 шт.)"]
        Fast["Быстрые (такт):<br/>SP (удивл.), BP (близ.), TP (угроза)"]
        Event["Событийная:<br/>AP (Адрен., λ=10.0)"]
        Slow["Медленные (сессии/дни):<br/>SPe (серот.), CP (кортиз.), MP (мелат.)"]
        Motiv["Мотивационные:<br/>OP (орекс.), LP (лептин), GP (грелин), EP (эндорф.)"]
        Aggregator["АГРЕГАТОР λ_t"]
        Fast --> Aggregator
        Event --> Aggregator
        Slow --> Aggregator
        Motiv --> Aggregator
    end

    subgraph Ego["ЭГО-КОНТУР"]
        Buffer["Буфер событий (10 000)<br/>· приоритетное вытеснение"]
        Anchors["Якоря (3–10)<br/>· ревизия каждые 10 циклов"]
        Quarantine["Адреналиновый карантин<br/>(до 5 слотов, TTL 7 дн.)"]
        Mood["Настроение (серотонин)<br/>· поисковая активация при < 0.15"]
        Narrative["Нарратив (ежедневно)<br/>· embedding-якорь<br/>· аудит еженедельно"]
        Closure["Механизм «закрытия гештальта»<br/>· затухание покинувших"]
    end

    subgraph Sleep["ЦИКЛ СНА (HYPNOС) — периодически"]
        Triggers["Триггеры: хроно, дельта, энтропийный, кортизоловый, дрейф-триггер, ручной"]
        Lethe["Lethe (Затухание)<br/>· decay адапт.<br/>· относит. порог<br/>· consol. decay 0.999"]
        Mnemosyne["Mnemosyne (Консолидация)<br/>· изолированная дистилляция<br/>· TIES-Merging (сортировка)<br/>· early stopping, бюджет времени<br/>· аудит адреналина и импринтов"]
        Erebus["Erebus (Очистка)<br/>· удаление проф.<br/>· калибровка<br/>· архивация<br/>· ревизия якорей"]
        Triggers --> Lethe --> Mnemosyne --> Erebus
    end

    subgraph Protection["ЗАЩИТА ИДЕНТИЧНОСТИ"]
        Mirror["Зеркало (Mirror)<br/>· AUC 0.8/0.9/0.85<br/>· Независимый аудитор<br/>· Канареечные промпты"]
        Golden["Золотой стандарт<br/>· 100 промптов v0<br/>· 10% веса в Зеркале<br/>· ежеквартальное расширение"]
        Ethics["Этический классификатор<br/>· DeBERTa INT8<br/>· PromptGuard<br/>· Truth Probes<br/>· двойной буфер"]
        Drift["Кумулятивный детектор<br/>· JS-дивергенция<br/>· триггер на Сон<br/>· ревизия якорей"]
    end

    subgraph Storage["ХРАНИЛИЩА"]
        Redis["Redis Cluster<br/>· профили (TTL 7д, версион.)<br/>· bond_state<br/>· веса адаптеров (LRU)<br/>· блокировки (Redlock)<br/>· Эго-буфер, гормоны<br/>· карантин (TTL 7д)"]
        S3["S3 (холодное)<br/>· source_dialogs (TTL 90д)<br/>· consolidation LoRA (3 верс.)<br/>· золотой стандарт<br/>· чекпоинты Призм<br/>· логи и метрики"]
        Cache["Локальный кэш реплик<br/>· горячие адаптеры (GPU LRU)<br/>· профили (RAM LRU)<br/>· fallback read-only"]
        Interfaces["Интерфейсы: StorageInterface, LockInterface<br/>(in-memory → Redis без рефакторинга ядра)"]
    end

    User --> Online
    Online --> Prisms
    Online --> Ego
    Online --> Sleep
    Sleep --> Protection
    Protection --> Storage
```
